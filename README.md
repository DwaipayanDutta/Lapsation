# 🧠 Lapsation

A lightweight model for detecting lapses in attention and focus.

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)
![Status](https://img.shields.io/badge/Status-Active-success.svg)

## 📋 Overview

Lapsation is a model designed to detect and analyze lapses in attention. It provides tools for monitoring focus patterns and identifying periods of reduced attention.

## 🚀 Features

- ⚡ **Fast Detection** - Real-time lapse detection
- 📊 **Analytics** - Track attention patterns over time
- 🔧 **Easy Integration** - Simple API for embedding
- 📈 **Visualization** - Built-in HTML dashboard

## 🛠️ Installation

```bash
pip install -r requirements.txt
```

## 📖 Usage

Run the application:

```bash
python api_app.py
```

Then open `lapsation_app.html` in your browser.
