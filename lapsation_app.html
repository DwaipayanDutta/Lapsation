⚙️ Model Pipeline
Build base data, engineer features, train XGBoost lapsation classifier
Pipeline Steps
📦
1. Load PKL Tables
gnmt_customer_master, GNMT_POLICY, gnmt_policy_detail, remt_receipt, GN_CONTRACT_STATUS_LOG
🔗
2. Build Base Master
Join policy → customer → address → detail → riders → payments → status
🔧
3. Feature Engineering
NUM_PAYMENTS, NUM_RIDERS, NUM_STATUS_CHANGES, DAYS_TO_DUE, PAYMENT_FREQ_RATIO, RIDER_DENSITY
🎯
4. Target Definition
IS_LAPSED = 1 when V_CURR_STAT_CODE == "NB022"
🤖
5. XGBoost Classifier
n_estimators=300, max_depth=5, lr=0.05, scale_pos_weight=3 (handles imbalance)
💾
6. Save & Serve
Model saved to models/xgb_lapse_model.pkl, served via /predict API

Model Configuration

            

              
LLM: TinyLlama-1.1B-Chat-v1.0

              
Embeddings: all-MiniLM-L6-v2

              
Reranker: ms-marco-MiniLM-L-6-v2

              
Vector Store: ChromaDB 0.6.x (langchain-chroma)

              
Chunk Size: 600 tokens / 120 overlap

              
Lapse Classifier: XGBoost (n=300, depth=5, lr=0.05)

              
scale_pos_weight: 3 (handles class imbalance)

              
Explainability: SHAP TreeExplainer — top 5 factors per policy

              
Batch Scoring: Full portfolio scored after each training run
